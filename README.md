SLA 洛杉矶系列可以理解为 CN2 GIA-E 的企业版：机器换成 AMD 专属核心加本地 NVMe RAID-10 存储，提供 99.99% 的 SLA 协议，机房拿到过 SOC 1/ISO 27001 等一堆认证，官方页面明确写了每两周可以免费更换一次 IP。价格也贵一截，季付 $65.89 起步，更适合拿来做正经生意的生产环境。

## 流量超限、退款和换 IP 的规则

这三条规则社区问得最多，也最容易踩坑，整理如下。

**流量用超了会怎样？** 不会产生任何超额费用——搬瓦工的机制是流量用尽后 VPS 被暂停，等账单周期重置后自动恢复，不存在“天价账单”这回事。但注意：没办法单独加钱买流量，暂停期间机器也不能操作。急用的话只有三条路：等重置、升级到更高流量套餐，或者把机房迁到流量比例更有利的位置。

**退款政策怎么算？** 官方提供 30 天退款保障，但附带条件不少：账户创建 30 天内、首次申请退款、名下 VPS 数量少于 3 台、累计支付金额低于 100 美元且支付次数少于 10 次，同时 IP 未被封禁。满足条件的申请一般能全额原路退回。给新用户的实际建议是：拿到手头几天内把延迟、丢包、速度都测完，别拖到第 29 天。

**IP 被封或想换 IP？** SLA 洛杉矶系列每两周可免费更换一次 IP；其他系列的换 IP 方式以面板内实际显示为准。这也是为什么下单前先想好机房和线路——选对了，后面很多麻烦根本不会发生。

**月付和年付差多少？** 差别很大。入门 KVM 只有年付档；80G KVM 月付 $19.99 但年付 $199.99（相当于打了约 8.3 折）；CN2 GIA-E 入门档只有季付和年付。预算允许时，长周期基本都更划算，配合循环优惠码再叠一层。

**缺货了怎么办？** 热门位置（尤其是 GIA 系列的优质机房）经常处于缺货状态，官方没有固定补货时间表。社区库存监控页可以看实时状态，等补货比反复刷新官网省心。

**能跑什么？** 1GB 内存的入门档，跑轻量建站、反代、开发测试环境、常驻的小型服务都在合理范围内；要跑数据库加应用的组合，建议从 4GB（80G KVM）档位起步。全系默认 1 个 IPv4 加一个 /64 的 IPv6 子网，完整 root 权限。

**和别家比值得买吗？** 取决于你要什么。单看配置价格，同价位能找到硬盘更大的商家；但“大陆方向全天候的线路质量 + 免费机房迁移 + 多年稳定的口碑”这个组合，是搬瓦工真正的护城河。你的业务越依赖这条链路，它的溢价就越值。
